**Unlocking Generalization in Polyp Segmentation with DINO Self-Attention "Keys"**

Each model comes with its own dedicated folder containing the complete training and testing code, implemented using PyTorch Lightning. To train a model, simply run the `main.py` file within the corresponding folder. This will automatically handle the training, validation, and testing processes across the selected data fold.

The dataset is split into 12 data folds, which are provided in the `gener_folds` folder. Additionally, we have included code to calculate the model's parameters and inference time.
